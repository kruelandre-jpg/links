Política de Privacidade

Esta política vale para o aplicativo usado pela equipe do Dr. André Kruel para gerenciar o canal "Canal da Artrose com Dr. André Kruel" no YouTube.

Quais dados usamos

Pela API oficial do YouTube, o aplicativo lê os comentários públicos feitos nos vídeos do canal (nome público do autor e texto do comentário) e publica respostas em nome do próprio canal. Não acessamos dados privados de quem comenta.

Para que usamos

Os dados servem só para ler e responder comentários do canal. Perguntas sobre saúde não recebem resposta automática: são revisadas pela equipe e respondidas apenas com orientações gerais, sem substituir uma consulta.

Compartilhamento e venda

Não vendemos nem compartilhamos esses dados com terceiros, nem os usamos para publicidade.

Guarda e exclusão

Guardamos apenas um registro interno das respostas, pelo tempo necessário para organizar o atendimento. Para pedir a exclusão de algum dado, escreva para o e-mail abaixo. O acesso do aplicativo pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Também seguimos os Termos de Serviço do YouTube e a Política de Privacidade do Google.
